# 取景教练 · Photo Coach

一个纯前端的「拍照教练」网页应用：打开相机 → 检测画面里的人 → 给出距离、站位、姿势和曝光的即时提示。全部计算在本机浏览器完成，画面不上传。

## 能做什么

| 模块 | 能力 | 说明 |
| --- | --- | --- |
| 打卡点 | 地图标注机位、距离/方位/步行时间、黄金时刻、一键导航 | 机位由你自己存（存在浏览器本地）；可选填高德 Key 搜附近 POI |
| 姿势 | 12 个手绘骨架姿势，可按场景/地点/风格筛选 | 骨架以半透明叠加在相机画面里，照着摆即可 |
| 拍照指导 | 实时姿态对比打分 + 距离估算 + 主体占比 + 构图/曝光提示 | MediaPipe Pose 在本机跑，约 5–10 fps |
| 落片 | 一键拍照，把画面（含骨架提示可选）存成 PNG | 也可用「用照片测试」拿本地图片先试效果 |

## 快速开始

```powershell
cd D:\dsh-workspace\photo-coach
node server.mjs
# 打开 http://localhost:8420/
```

必须用 `http://localhost` 或 `https://` 打开——浏览器只在安全上下文里允许摄像头（`getUserMedia`）。直接双击 `index.html`（`file://`）摄像头会不可用，但「用照片测试」仍能用。

## 使用流程

1. **打卡点**：先点「📍 定位」，再「+ 存当前机位」记录你站的位置（可填焦段、机位高度、最佳时段）。列表按距离排序，点条目看详情、点「照这个拍」直接带到相机页。
2. **姿势**：挑一个姿势，标签写着「暖/清冷/活泼」和适用场景；选中的姿势会成为相机页的对比目标。
3. **拍照**：点「开启相机」授权摄像头；把被拍者放进取景框，面板会显示当前距离、建议距离、主体占比、姿态分和三条以内的人话提示。
4. **构图目标**：按「全身/半身/特写」切换目标；主体身高、镜头水平视角、骨架不透明度都可调，设置自动存本地。

## 图上标定与精度

- 地图用 Leaflet + 高德瓦片。高德瓦片是 GCJ-02 坐标，项目内置 WGS84 ↔ GCJ-02 双向转换，不做转换会让标记偏 300–700 m。
- 距离是按针孔模型估算的：用「躯干像素长度 ÷ 躯干实际长度（0.29 × 身高）」反推，**不是测距仪**，正常误差在 ±20%~30%。画面里人只露上半身时误差更大，所以从照片测距时会额外提示「脚被裁了」。
- 曝光只做亮度采样（0–255 的主画面均值）给方向性建议，不做直方图分析。

## 可选：搜附近打卡点

「搜附近」需要一个高德开放平台的 **Web 服务 Key**（不是 JS API Key）：

1. 到高德开放平台控制台建应用，加「Web 服务」类型的 Key；
2. 点右上角 ⚙ → 填入 Key → 保存；
3. 回「打卡点」页点「搜附近」。

Key 只存在你的浏览器 `localStorage` 里，不会发到别处（请求直接打到 `restapi.amap.com`）。

## 目录结构

```
photo-coach/
├─ index.html            三个页签的骨架
├─ server.mjs            零依赖静态服务器（端口 8420，支持 .wasm/.task 的 MIME）
├─ css/style.css         深色主题 + 移动端断点
├─ js/
│  ├─ app.js             装配层：路由、定位、机位 CRUD、相机循环
│  ├─ geo.js             WGS84↔GCJ-02、haversine、方位、日出日落与黄金时刻
│  ├─ spots.js           机位存取（localStorage）、地图、POI 搜索、导航链接
│  ├─ poses.js           12 个骨架姿势数据 + 绘制/缩略图
│  ├─ coach.js           MediaPipe 封装、度量、姿态对齐与打分、提示生成
│  └─ camera.js          摄像头、画面裁切映射、快门合成、下载
└─ vendor/               本地依赖（离线可用）
   ├─ leaflet/           Leaflet 1.9.4
   ├─ mediapipe/         @mediapipe/tasks-vision 0.10.14 的 wasm 与 bundle
   └─ models/            pose_landmarker lite / full（.task）
```

## 已知限制

- 单线程 MediaPipe：桌面约 5–10 fps，老手机可能更慢；设置里可切到 `lite` 模型提速。
- 姿态打分只比 10 个肢体段的角度和长度比，不看手部细节，所以「手指比心」这类细微动作分数会偏低。
- 前置摄像头画面是镜像显示的，距离/比例不受影响。
- 机位数据只在这个浏览器的本地存储里，换设备或清缓存会丢；没有账号体系，也没做导出（可自行在控制台导出 `photo-coach.spots.v1`）。
- iOS Safari 需要用户手势触发摄像头与陀螺仪授权，「开启相机」按钮就是那个手势。
